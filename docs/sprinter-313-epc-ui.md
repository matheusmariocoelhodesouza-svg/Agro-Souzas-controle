# UI do EPC no Comando 360

O catálogo técnico possui dois modos:

1. **Peças e componentes** — busca geral por nome, código OEM, localização e item EPC.
2. **Vistas explodidas** — agrupamento por vista, com carregamento sob demanda dos itens numerados.

Cada item detalhado mostra código, posição, quantidade, tipo, localização, sintomas, testes sugeridos e ferramentas. Quando a vista original é apenas uma referência de terceiro, a interface não republica a imagem: apresenta o link para abrir a fonte original.

A consulta de componentes é paginada em lotes de IDs para evitar URLs excessivamente grandes conforme o microcatálogo cresce.
