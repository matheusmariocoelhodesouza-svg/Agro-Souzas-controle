# Gestação 360
V1 isolada do aplicativo de acompanhamento gestacional.

## V1
- idade gestacional automática
- Home
- Bebê
- Diário
- Exames
- Agenda
- Preparativos

Dados médicos exibidos pelo app são de acompanhamento e não substituem avaliação profissional.


## Arquitetura familiar e continuidade
- Uma conta pode acompanhar mais de um filho.
- Cada criança mantém uma linha do tempo contínua: gestação → nascimento → infância.
- Perfis previstos: mãe e pai/parceiro, ligados à mesma criança.
- Dados maternos sensíveis são privados por padrão; compartilhamento exige permissão.
- No nascimento, a gestação muda para a fase bebê sem perder exames, diário, agenda ou histórico.
- Registro neonatal: data/hora, peso, comprimento e perímetro cefálico.
- Pós-nascimento: crescimento, consultas, vacinas, alimentação, sono, medicamentos, dentição e marcos do desenvolvimento.
